I am an engineering student at Vishwakarma University who learns by building. My main project is VEGA, a vibe-coded AI assistant that runs as an installable web app and picks between models depending on what you ask.

I build by describing what I want to an AI coding assistant, testing the result and iterating. I care about the details that make a tool feel finished, and when something does not work out, such as a hosting plan I could not afford, I change the design and keep going.

VEGA

A hybrid AI assistant PWA. VEGA classifies each message and sends it to the model that suits it, then streams the answer back with a fallback if one provider fails.

VEGA is a vibe-coded project. I direct an AI coding assistant, review what it builds, and iterate until it works.

FastAPIVanilla JSNeon PostgresGroqGeminiVercelRenderVibe coded

View the repository

  • Model routing. Quick local-intent requests go to Groq for speed. Everything else goes to Gemini, with automatic fallback if Groq fails.
  • Agent loop. A plan, act and check loop handles multi-step requests.
  • Boot sequence. A circuit-line V mark draws itself in, then morphs into the 650-particle orb. This page borrows the same idea with a P for Pranav.
  • Accounts and storage. bcrypt authentication, Postgres on Neon, and a SQLite fallback.
  • Next. Background tasks that run unattended, and a second brain that pulls context from Google Drive.

ASAP

A team project for college. ASAP is a parking system that shares spare spaces in real time. It works with the staff and gates a lot already has, so it makes their job easier instead of replacing them.

Team of 4Semester projectMallsHousing societies
  • Malls. Existing CCTV shows which spaces are free, FASTag or a QR code at the gate identifies the car, drivers can pre-book, and paying at exit frees the space.
  • Housing societies. Visitors pre-book a space, and the guard scans them in and out at the gate.
  • Approach. Software that supports existing ticket staff and guards, with no new hardware crew to replace them.
